Explorador de cócteles

Consume la API TheCocktailDB disponible en RapidAPI mediante Fetch API.


Nota: Utilice la API key de prueba proporcionada en la documentación de la API, ya que no se pudo configurar el plan gratuito de RapidAPI.

Los endpoints utilizados son: /search.php?s= y /filter.php?c=.

Detalle

Credenciales de RapidAPI

Cree una cuenta en RapidAPI, suscríbase al plan gratuito de la API The Cocktail DB y copie su clave. Los datos se guardan únicamente en el almacenamiento local de este navegador.

Ingrese su API key de RapidAPI.
Ingrese un host válido, por ejemplo the-cocktail-db.p.rapidapi.com.
